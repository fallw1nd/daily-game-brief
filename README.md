# 游戏圈动态

每天北京时间 12:00 计划发布的可核验游戏行业日报；事实窗口在 10:10 封窗。页面由结构化数据渲染，历史早晚报保持归档。

系统审查与运行边界见 [系统审查](docs/SYSTEM_REVIEW.md)，编辑调度见 [定时任务约定](docs/SCHEDULED_TASK_PROMPT.md)，发售发现见 [15天日历](docs/RELEASE_CALENDAR.md)。

## Local development

```bash
npm install
npm run dev
```

Run `npm run check` before submitting changes. Product data rules are documented in `AGENTS.md`; the visual system is documented in `DESIGN.md`.
